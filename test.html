Proof: Additive Inverse of a Binary Number

Let \(X\) be an \(n\)-bit binary integer represented in positional notation as:

\[X = \sum_{i=0}^{n-1} x_i \cdot 2^i, \quad \text{where } x_i \in \{0, 1\}\]

Bitwise Boolean Inverse

The bitwise boolean inverse (one's complement) \(\overline{X}\) flips every bit \(x_i\) from \(0\) to \(1\) or \(1\) to \(0\):

\[\overline{X} = \sum_{i=0}^{n-1} \overline{x}_i \cdot 2^i, \quad \text{where } \overline{x}_i = 1 - x_i\]

Sum of a Number and Its Inverse

Adding \(X\) and \(\overline{X}\) component-wise produces an \(n\)-bit value where every bit position contains \(1\):

\[X + \overline{X} = \sum_{i=0}^{n-1} x_i \cdot 2^i + \sum_{i=0}^{n-1} (1 - x_i) \cdot 2^i\] \[X + \overline{X} = \sum_{i=0}^{n-1} (x_i + 1 - x_i) \cdot 2^i = \sum_{i=0}^{n-1} 1 \cdot 2^i\]

Using the geometric series identity \(\sum_{i=0}^{n-1} 2^i = 2^n - 1\):

\[X + \overline{X} = 2^n - 1\]

Additive Inverse Modulo \(2^n\)

In fixed-width \(n\)-bit binary arithmetic (two's complement representation operating modulo \(2^n\)), the additive inverse \(-X\) is defined as the unique value satisfying:

\[X + (-X) \equiv 0 \pmod{2^n}\]

Algebraically, this represents:

\[-X \equiv 2^n - X \pmod{2^n}\]

Algebraic Equivalence

Rearranging \(X + \overline{X} = 2^n - 1\) to isolate \(2^n - X\):

\[2^n - X = \overline{X} + 1\]

Substituting \(2^n - X\) into the modular expression for the additive inverse yields:

\[-X \equiv \overline{X} + 1 \pmod{2^n}\]

Thus, the additive inverse of an \(n\)-bit binary number \(X\) is equal to its bitwise boolean inverse \(\overline{X}\) plus \(1\).
