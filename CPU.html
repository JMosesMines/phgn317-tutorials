Central Processing Unit

An ALU can do several different logical and arithmetic operations, but it is far from a fully automatic machine. From where does it get its operands? To where does it store its results? What controls its operational sequence? All this is done by a Central Processing Unit, whose core is an ALU. The CPU also includes a Control Unit, and a set of Registers, which each have a special function. The CPU Control Unit is a Finite State Machine that controls everything else.

The registers in the CPU each have a critical job.

Register Name Purpose
PC Program Counter Contains the address of the next instruction to be fetched.
IR Instruction Register Contains the instruction currently being executed.
ACC Accumulator Working register used by the ALU to store operands and results.
MAR Memory Address Register Contains the address currently being accessed in memory.
MDR Memory Data Register Contains data being transferred between the CPU and memory.

Fetch-Decode-Execute

The CPU repeatedly cycles though three main steps:

  1. Fetch an instruction from memory
  2. Decode the instruction, to see what data it needs for its operation
  3. Execute the instruction. The execution is performed by the ALU, when triggered by the Control Unit

In performing these steps, memory addresses and working data are transmitted through the CPU between its registers, on the CPU's internal bidirectional busses. The main job of the Control Unit is to synchronize the Read Enable and Write Enable signals that control access to the bidirectional busses.

Instruction Set

The Instruction Set is the list of instructions, or opcodes, that the ALU is designed to execute. A sequence of these simple operations can be systematically composed to accomplish complex calculations. The instruction set is the bridge between a computer's hardware and its software. The instruction set would include, for example, opcodes to fetch data from memory, perform an operation on the data, and store the result of the operation back into memory.
