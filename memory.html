Memory

A block of computer memory consists of a 2-dimensional grid of flip-flops (or latches). The width of the grid is n, the number of bits in each word, and the length is 2k, where k is the number of address bits. Memory write and read actions are gated, on the input and output side of each flip-flop, by enable signals. An address decoder inside the memory IC selects which word is to be written or read.

Signal I/O

Timing sequence

Memory operations must proceed in a certain sequence. For a Write operation, the CPU sets the value of the Address and Data Input busses, and then activates and deactivates the Write Enable Signal, to latch the data into memory. Then the busses are ready for the next operation.

For a Read operation, the CPU sets a value on the Address bus, and then activates the Read Enable signal. The memory device then sets the value of the Data Output bus. After reading the data, the controller then deactivates the Read Enable signal. Then the busses are ready for the next operation

Bidirectional Bus

To save space, we can reduce the number of wires going to the memory IC by making the Data Bus Bidirectional. We accomplish this by using Three-state logic. A three-state, or tri-state buffer can pass a high or low signal through, like a closed switch, or, third, it can leave its output node floating, not driving it at all, like an open switch. This lets the memory circuit receive data from the data bus, when Write Enable is active, or drive data to the data bus, when Read Enable is active.

Three-State Buffer

The bi-directional bus is enabled by the Tri-State Buffer. To understand how it works at a transistor level, first make sure you understand how a basic CMOS inverter is made from MOSFETs. In this circuit, M2 and M3 function just like a standard CMOS inverter. Exactly one of the two transistors is always ON, or conducting, and the other is always OFF, depending on the value of the Input signal. The Tri-State Buffer circuit adds two more transistors, controlled by a second input, the Enable. When Enable is High, both M1 and M4 are ON, so that the Output can source or sink current to drive its node to High or Low, according to the value of the Input (A) signal. When Enable is low, both M1 and M4 are off. Their channels are in series with the channels of M2 and M3, so this prevents the circuit from sourcing or sinking any current at all, leaving the output floating.

Memory-mapped peripherals

Once we have an efficient bus structure though which to bidirectionally transmit digital data to or from certain memory addresses, we can also use this same bus structure to interface with peripheral devices such as digital sensors and actuators, by assigning a specific address range to those peripherals. In this way, the CPU can send and receive data to and from peripheral devices in the same way that it sends and receives data to and from memory, simply by addressing the device. An address decoder enables the peripheral device when its address matches the address on the Address Bus. This is called Memory-mapped I/O.
