Memory

A block of computer memory consists of a 2-dimensional grid of flip-flops (or latches). The width of the grid is n, the number of bits in each word, and the length is 2k, where k is the number of address bits. Memory write and read actions are gated, on the input and output side of each flip-flop, by enable signals. An address decoder inside the memory IC selects which word is to be written or read.

Signal I/O

Timing sequence

Memory operations must proceed in a certain sequence. For a Write operation, the CPU sets the value of the Address and Data Input busses, and then activates and deactivates the Write Enable Signal, to latch the data into memory. Then the busses are ready for the next operation.

For a Read operation, the CPU sets a value on the Address bus, and then activates the Read Enable signal. The memory device then sets the value of the Data Output bus. After reading the data, the controller then deactivates the Read Enable signal. Then the busses are ready for the next operation
